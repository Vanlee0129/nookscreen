Download APK Full installation guide
  1. Copy the APK to USB and install it from the TV’s file manager.
  2. Open NookScreen. Press ↑, then OK on the status button for Control Center.
  3. Set NookScreen as the default Home app in Android settings, or use Make NookScreen Your Home Screen.
